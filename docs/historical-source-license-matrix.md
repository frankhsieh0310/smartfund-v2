# Historical Source License Matrix

| Licence state | Meaning | Production action |
| --- | --- | --- |
| `PRODUCTION_APPROVED` | Terms, scope and redistribution rights recorded | Adapter/integration may proceed |
| `LICENSE_REVIEW_REQUIRED` | Source found but rights not approved | Discovery/validation only; no ingestion |
| `VALIDATION_REFERENCE_ONLY` | May compare values manually where permitted | Never cache or redistribute source content |
| `LICENSE_REQUIRED` | Paid or institutional contract required | Do not access without contract |
| `TO_VERIFY` | Access, coverage or terms not yet confirmed | No Production use |

Current catalog has no new Financial provider marked `PRODUCTION_APPROVED`.
Official accessibility does not by itself settle commercial or redistribution
rights. This avoids locking a financial schema or ingestion pipeline to an
unapproved source.
