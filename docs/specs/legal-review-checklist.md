# 法務確認清單（Legal Review Checklist）

這份文件只記錄「目前已知、尚待法務/授權確認」的事項，不代表已核准使用。每項标明目前用途與風險等級。

## 1. Yahoo Finance 商品期貨資料（chart API / finance.yahoo.com）

- **目前用途**：自用研究與唯讀技術盤點（`docs/specs/technical-screener-reverse-lookup.md`），以及
  `app/api/cron/yahoo-commodity/route.ts`（目前僅影子模式，未開寫入、未部署）。
- **狀態**：`query1.finance.yahoo.com/v8/finance/chart/...` 與 `finance.yahoo.com/quote/...` 皆為
  **非正式／未公開文件化的端點**，沒有官方發布的、明確允許程式化或商業用途的使用條款。
- **風險**：若未來這項資料要**用在收費的 App／對外服務**（不只是內部研究），必須先確認：
  1. Yahoo/Verizon Media 現行服務條款是否允許這種程式化擷取與再分發（即使只是顯示摘要數字）。
  2. 是否需要改用 Yahoo 官方授權的資料方案，或改用下列其他來源替代。
- **下一步**：轉為付費/對外功能前，必須取得法務或商業授權確認，不得僅憑「目前免費可抓到」就視為已核准。

## 2. FRED（St. Louis Fed）

- **用途**：原油（`DCOILWTICO`）、天然氣（`DHHNGSP`）每日核對 Yahoo 數值的參考來源。
- **授權**：FRED 官方標示 "Public Domain: Citation Requested"（美國聯邦政府資料，公眾領域）。
- **已知限制**：FRED 使用條款明確禁止將其內容/API 用於「開發或訓練 AI」——若本專案其他 AI 子系統
  （例如共識雷達的 AI 萃取）未來可能間接用到這份資料做訓練用途，需要另外法務確認是否牴觸。目前
  僅做每日數值核對（非訓練用途），風險較低，但應持續留意。
- **現況**：`.env` 已有 `FRED_API_KEY`（既有專案用途，非本次新申請）。

## 3. EIA（美國能源資訊署）

- **用途**：原油/天然氣官方價格的候選替代來源。
- **授權**：美國政府公開資料，一般可自由使用。
- **現況**：尚未申請 API Key，本專案目前未串接。

## 4. LBMA（London Bullion Market Association）

- **用途**：黃金/白銀官方定盤價的候選來源。
- **授權**：**VERIFIED 需要付費授權**（LBMA 官網明確寫明金銀鉑鈀報價為付費 IBA 授權內容，沒有免費方案）。
- **結論**：若要使用 LBMA 官方定盤價，必須先完成採購/授權流程，不是技術問題。

## 5. 一般原則

- 目前整個商品資料子系統（含本次復活的 `yahoo-commodity` 排程）定位為**自用研究**，未對外開放、未用於
  任何收費功能。
- 任何要把這些資料放進會員付費功能、或對外公開展示的計畫，上線前都要回到這份清單，逐項確認授權狀態，
  而不是只看「資料抓得到」。
